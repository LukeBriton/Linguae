# 廣府話

## 标准语

|        | 粤语-广府/粤海片         | 北京官话-京师片                    |
| ------ | ----------------- | --------------------------- |
| **名称** |                   |                             |
| 泛指     | 粤语、（港澳）广东话、（两广）白话 | 汉语、中国话、国语、华语、（清末）官话         |
| 特指     | 广府话、广州话           | 现代标准汉语、新国音、普通话、国语、华语        |
| **形式** |                   |                             |
| 书面     | 粤文、（嘲）粤喃文&粤假名     | （罕）汉文、中文、国文、华文              |
| 口语     | 粤白、广白             | 官白、京白                       |
| **标准** |                   |                             |
| 基础方言   | 省城话、广州话           | 京音、北京话、京片子、京腔               |
| 方言点    | 老派城内音、（附会）老派西关话   | 建国前后北城/内城音、（伪）滦平            |
| 标准变体   | 广州粤语、香港粤语         | （大陆）普通话、（台湾）国语、（新马）华语、地方普通话 |
